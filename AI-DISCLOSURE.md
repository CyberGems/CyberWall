# AI disclosure

CyberWall is developed with the help of frontier AI coding assistants.
Architecture, design decisions, code review, testing and releases are
carried out by the maintainer. AI output is treated as a draft: every change
is read, verified and committed deliberately. Commit messages intentionally
carry no automated AI signatures. Automated checks (builds, tests and
repository conventions) run in CI on every push; they complement, not
replace, human review.

This statement is about how the software is built. CyberWall itself ships no
AI features: it makes no model calls at runtime.

This statement covers the source code and documentation in this repository.
Third-party dependencies keep their own licenses. The repository LICENSE is
the only grant of rights for this code.

We do not record which model or prompt produced each line, and we make no
claim about the training data of the tools used. If you find a fragment that
looks copied from another project, please open an issue.
